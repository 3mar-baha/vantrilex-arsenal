# التحقّق

تنتهي المهمة حين يُثبَت الشيء، لا حين تعمل الشيفرة. يصف هذا الملف البوابات
الست المفروضة، وماذا يفحص كلٌّ منها، والقاعدتين العلويتين: البوابة التي
يتعذّر تقييمها بوابة فاشلة، والتكليف لا يُؤكَّد إلا حين ترسخ نتيجته. وتوثَّق
نظافة التوثيق أدناه خطوةَ تنظيف إضافية؛ وهي ليست واحدة من الست. وقائمة
فحص كل تغيير في
[13-CONTRIBUTING-WORKFLOW.md](../13-CONTRIBUTING-WORKFLOW.md)؛ وتوصيلات CI في
[14-CI-RELEASE.md](../14-CI-RELEASE.md).

## `verify-registry.mjs`: الفحوص السبعة

يُشغَّل بالأمر:

```bash
node scripts/verify-registry.mjs
```

| الفحص | ما يثبته |
|---|---|
| `utf8-validity` | أن Markdown الفهرس يُفَك ترميزه UTF-8 صارمًا بلا تسلسل معطوب |
| `schema-conformance` | أن السجلّات الـ2,889 تفي بـ `registry/schema/catalog-v4.schema.json` |
| `row-count-integrity` | أن عدد كل عنوان قسم وعدد المحدَّد افتراضيًا يطابقان التحليل |
| `install-command-invariant` | أن لا سجلّ يدّعي `verified` مع `install_cmd` فارغ |
| `orphan-references` | أن مراجع المعرّفات الـ45 عبر مدخلات التداخل الـ56 تُحَل كلها |
| `duplicate-ids` | أن لا معرّف يصطدم داخل نوعه |
| `mcp-name-normalization` | أن أسماء خوادم MCP الـ910 تبقى فريدة بعد تسوية الفهرس v2 |

والأحكام PASS أو FAIL أو SKIPPED. والفحص المتخطّى يُبلَّغ تخطيًا لا
اجتيازًا أبدًا. وينتهي التشغيل بغير الصفر على أي FAIL. وحين يتعذّر تحليل
الفهرس أصلًا، يفشل فحص المخطط وتُبلَّغ الفحوص الأربعة الباقية SKIPPED مع
علّة التحليل سببًا.

## فحص النسخة الآلية للفهرس

```bash
node scripts/generate-catalog-json.mjs --check
```

يثبت أن `registry/catalog.json` (ومع `--markdown` / `--indexes` الجدولَ
والفهارس) محدَّثة بالبايت مع المصادر. وأي انحراف يفشل مع أمر الإصلاح
بعينه. وتفاصيل إعادة التوليد في
[07-CATALOG-GENERATION.md](../07-CATALOG-GENERATION.md).

## فحص الفهرس والاختيار

تسمّي `AGENTS.md` وCI السكربتَ `scripts/verify-catalog.mjs` البوابةَ التي
تثبت صدق كل سجلّ في الفهرس وأن كل مكوّن مختار يُحَل. وهذا السكربت موجود ويجتاز 20/20
مقابل `registry/catalog.json` (2,889 سجلًّا، بلا حالة `pending`) و`.opencode/equip.manifest.json`
(145 رمزًا مختارًا)، ومنها فحص شكل لكل نوع قابل للاختيار —
ففحص `command-shape/cli` الذي يجتاز على 64 سجلّ `cli` يُبلَّغ على هذا النحو لا
اجتيازًا صامتًا فارغًا. انظر [09-KIT-LOCK.md](09-KIT-LOCK.md).

## فحص صيغة المهارة

```bash
node scripts/verify-skills.mjs
```

تفرض عشرة فحوص عقدَ صيغة ملف المهارة: الاكتشافُ وشكل المجلد المخفَّض
الموصّل بشرطات، ومفاتيح المقدّمة، ومطابقة اسم المقدّمة لمجلده، والوصف
ذي الجملة الواحدة بصيغة الغائب مع مشغّل متقدّم، وعناوين المتن السبعة
اللازمة بالترتيب، وبلا مواضع مؤقّتة، وبلا سلاسل أدوات مستبعَدة، ونظافة
الملف، وقاعدة البيت الواحد لكتل الآليات المشتركة، والفحص المتقاطع لخريطة
المراحل. وهو يقيّم حاليًا 37 مجلد مهارة ويجتاز 10/10.

## سكربتات الصدفة

```bash
shellcheck scripts/*.sh .githooks/*
```

ويشغّل CI فوق ذلك `bash -n` على كل سكربت وكل خطاف git، ثم `node --check`
على كل ملف `.mjs`. وتحمل سكربتات التنسيق السبعة كلها سطرَ `#!/usr/bin/env
bash` الافتتاحي وبتَّ التنفيذ؛ ويؤكّد CI الأمرين.

## TypeScript الإضافة

```bash
npx tsc --noEmit
```

تُفحَص أنواع الإضافة بمُدقِّق المشروع المثبَّت نفسه. ويشغّل CI هذه الخطوة
بلا شرط ويُبلَّغ SKIPPED حين لا تحمل الشجرة `tsconfig.json`: فالمشروع بلا
TypeScript لا حكم له، ولا PASS مجاني أبدًا.

## نظافة التوثيق

```bash
npx markdownlint-cli "**/*.md"
```

نظافة التوثيق خطوة تنظيف إضافية، وليست واحدة من البوابات الست المفروضة:
فلا يشغّلها CI، وغيابها عن تشغيل ليس فشل بوابة.

ويتبع نثر المستودع `.markdownlint.jsonc`: فالفقرات الطويلة والجداول
العريضة لا تُغلَّف بقسوة، وتباعد أعمدة الجداول حرّ، ومخطّطات ASCII في
كتل مسيَّجة، ويفتتح كل مستند عنوانًا واحدًا من المستوى الأعلى.

## قاعدة القائمة البيضاء لكل فرع

يُبقي حارس انضباط التوثيق في `.opencode/plugin/arsenal.ts` التوثيقَ داخل
المجموعة المعيارية: سلسلة `docs/` المرقّمة، ومجلدا الأرشيف والمواصفات،
والسجلّ، و`.opencode`، و`brand` (مسموح به لأن مواصفة الهوية البصرية تعيش
هناك)، وملفات الجذر الثمانية المسمّاة. فكتابة Markdown خارج تلك القائمة
ممنوعة (BLOCKED) أو منذَرة (WARN في وضع التحذير)، مع رسالة تسمّي المجموعة
المسموحة وكيف تُوسَّع. وتسير السلسلة المرقّمة لمشروع الهدف من `00` إلى
`27`؛ وترقيم هذه المجموعة الخاصة بالترسانة من `00` إلى `21` هو النظير
الخاص بتوثيق المستودع، لا السلسلة نفسها.

## قانون الترسّخ

لا يُؤكَّد التكليف إلا حين ترسخ نتيجته، لا على قول وكيل فرعي. يجعل القانون
الدستوري 5 (انظر [05-DOCTRINE.md](05-DOCTRINE.md)) من ذلك قاعدة تحقّق:
فمسار العمل منجَز حين تُراجَع تكاملته وتُعتمَد وتُدمَج — والعمل المُبلَّغ بلا
نتيجة راسخة عمل غير منجَز. وآليات أشجار العمل التي تفرض ذلك في
[11-WORKTREES.md](../11-WORKTREES.md).

## البوابة التي يتعذّر تقييمها بوابة فاشلة

إذا تعذّر تشغيل فحص — أداة مفقودة أو ملف مفقود أو إعداد مفقود — فذلك فحص
فاشل لا متخطًّى. فاذكر ذلك في وصف التغيير بدل ترك البوابة تبدو خضراء.
ويمثّل CI ذلك بالإبلاغ SKIPPED مع السبب مفصَّلًا (لا `tsconfig.json`، لا
مستند نقطة تفتيش)؛ فيعامل القارئ البشري كل سطر كهذا بندًا مفتوحًا، ويرفض
مسار الإصدار في [14-CI-RELEASE.md](../14-CI-RELEASE.md) الشحنَ فوق حرّاس
مفتوحين.
