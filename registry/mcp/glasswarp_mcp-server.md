# glasswarp/mcp-server

**Kind:** MCP Servers

**Description:** See and control a real Windows PC you own from any MCP client, locally or remotely. Hosted MCP (`https://mcp.glasswarp.com/mcp`) or `npx @glasswarp/mcp`. Observe (UIA + screenshots), click/type/drag/scroll, launch apps, owner Live View. BYOH — your machine, your key; you bring the model.
