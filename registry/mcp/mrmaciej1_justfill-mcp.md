# mrmaciej1/justfill-mcp

**Kind:** MCP Servers

**Description:** Fill existing AcroForm, flat, and scanned PDF forms from AI agents. Detect and visually review fields, save deterministic templates, map JSON values, and preview filled output before export. Use the hosted OAuth endpoint or run locally with `uvx justfill-mcp`; MIT licensed.
