# MailFlat/mailflat-sdks

**Kind:** MCP Servers

**Description:** Email inboxes for agents, with the one-time code returned as a field instead of a regex over the message body. Addresses are permanent; only the messages expire, on a retention window you choose. `uvx mailflat-mcp`
