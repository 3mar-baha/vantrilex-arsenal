# BlazingCDN/BlazingCDN-MCP

**Kind:** MCP Servers

**Description:** Official BlazingCDN server: manage CDN zones (TTLs, compression, on-the-fly image resizing, HLS/DASH), purge and warm up cache, traffic metrics, custom domains, cloud storage and Video CDN. 52 tools, read-only by default with opt-in write/delete. Install: `npx -y @blazingcdn/mcp`.
