# tverney/mcp-agent-memory

**Kind:** MCP Servers

**Description:** Persistent agent memory via filesystem-native consolidation daemon. Agents read/write/search memory through MCP; a background daemon handles consolidation and extraction. Works with Kiro, Claude Desktop, Cursor, and any MCP client. `npx mcp-agent-memory --setup`
