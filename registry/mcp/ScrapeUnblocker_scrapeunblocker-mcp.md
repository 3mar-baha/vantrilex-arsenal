# ScrapeUnblocker/scrapeunblocker-mcp

**Kind:** MCP Servers

**Description:** Fetch any web page's HTML (or AI-parsed JSON, or Google results) through the ScrapeUnblocker anti-bot API (Cloudflare, DataDome, PerimeterX, Akamai, Shape), using your own API key. Three tools: `fetch_html`, `fetch_parsed`, `google_search`. Install: `npx -y scrapeunblocker-mcp`.
