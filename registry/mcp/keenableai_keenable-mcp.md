# keenableai/keenable-mcp

**Kind:** MCP Servers

**Description:** Live web search and clean-markdown page fetch over the Keenable web index. Two tools: `search_web_pages`, `fetch_page_content`. Keyless by default (1,000 req/hour); an optional API key lifts the cap. Hosted Streamable HTTP at `https://api.keenable.ai/mcp`, or run `npx -y @keenable/mcp`.
