# sp3ak/safenode-mcp-gateway

**Kind:** MCP Servers

**Description:** Policy proxy for MCP tool calls. Evaluates every call before forwarding; deny means it never reaches the downstream server. Warn forwards with a visible banner, review holds for human approval. Client-side redaction reports what it stripped so server-side rules still fire on data they never receive…
