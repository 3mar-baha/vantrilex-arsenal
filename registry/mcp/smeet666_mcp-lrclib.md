# smeet666/mcp-lrclib

**Kind:** MCP Servers

**Description:** Search tracks on LRCLIB and read their lyrics, including time-synced (LRC) lines with a timestamp on every line. Strips lyrics from search results, cutting a search from ~29k to ~800 tokens. No API key. `npx -y mcp-lrclib`
