# Lex-API/lexapi-mcp

**Kind:** MCP Servers

**Description:** EU legal research over EUR-Lex — 10 tools for structured search, CELEX/URL document fetch, recent Official Journal publications, inbound/outbound citation graph, and semantic search over case law + legislation. FREE tier available; semantic tools require a paid plan. Install: `npx -y @lexapi/mcp`.
