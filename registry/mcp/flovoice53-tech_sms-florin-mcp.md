# flovoice53-tech/sms-florin-mcp

**Kind:** MCP Servers

**Description:** Rent real UK phone numbers (EE/Three SIM cards, not VoIP) and receive SMS/OTP codes for WhatsApp, Telegram, Google, Discord, and more. 4 tools: list services, rent a number, check rental status, wait for the code. Install: `npx -y sms-florin-mcp`.
