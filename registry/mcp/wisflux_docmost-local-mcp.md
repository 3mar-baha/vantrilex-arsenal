# wisflux/docmost-local-mcp

**Kind:** MCP Servers

**Description:** MCP server for self-hosted [Docmost](https://docmost.com/) (an open-source Notion/Confluence alternative). Read and write spaces, pages, comments, and members from Claude, Cursor, or VS Code. Works on the free Community Edition. `npx -y @wisflux/docmost-local-mcp`
