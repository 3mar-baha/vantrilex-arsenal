# bobaba99/motionlint

**Kind:** MCP Servers

**Description:** Catch bad animations before they ship. 13 deterministic checks on the live page (duration, easing, stagger, exits, reduced-motion, touch-gated hover) with no API key or LLM, plus optional vision-LLM UX review across viewports. Install via NPM: `npx -y motionlint mcp`
