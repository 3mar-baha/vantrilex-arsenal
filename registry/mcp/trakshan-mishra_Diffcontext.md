# trakshan-mishra/Diffcontext

**Kind:** MCP Servers

**Description:** Static-analysis-powered context compiler for LLM coding agents. Parses Python repos into dependency graphs, selects the minimal code context for a change (callers, callees, related functions), and packs it into a token budget with a disclosure header. Optionally biases retrieval from the bug report…
