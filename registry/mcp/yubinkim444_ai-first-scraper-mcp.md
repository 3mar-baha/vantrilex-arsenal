# yubinkim444/ai-first-scraper-mcp

**Kind:** MCP Servers

**Description:** Three MCP tools for ad-free Markdown web scraping and search. `fetch_page` (URL → clean Markdown), `fetch_pages_batch` (up to 25 URLs in parallel), `search_web` (web search → top-k pages as Markdown). Works with Claude Desktop / Cursor / Cline. Install: `uvx ai-first-scraper-mcp`.
