# enmanuelmag/heimdall-mcp

**Kind:** MCP Servers

**Description:** Transparent proxy for any MCP server that intercepts all JSON-RPC messages, measures latency, and stores traces in SQLite, PostgreSQL, or MySQL. Exports OpenTelemetry (OTLP) spans to Jaeger, Tempo, or Grafana. Supports stdio, HTTP, and SSE transports. `npx @cardor/heimdall-mcp`
