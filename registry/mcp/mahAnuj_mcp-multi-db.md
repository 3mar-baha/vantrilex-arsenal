# mahAnuj/mcp-multi-db

**Kind:** MCP Servers

**Description:** One MCP server for PostgreSQL, MySQL, and SQLite. Unified read-only tools (`list_databases`, `list_tables`, `describe_table`, `run_query`) across all three engines with two-layer read-only enforcement (SQL-text guard + DB-level read-only transactions). Install: `npx -y mcp-multi-db`.
