# jaimenbell/rag-mcp

**Kind:** MCP Servers

**Description:** Minimal RAG-over-a-corpus retrieval tool: `search_knowledge(query, k)` embeds the query, vector-searches a local corpus and returns cited passages. Runs fully locally with no paid embedding API. `pip install jaimenbell-rag-mcp`
