# colapsis/transfa

**Kind:** MCP Servers

**Description:** Ephemeral file transfer for AI agents and CI/CD pipelines — upload any file, get a SHA-256-verified, TTL-enforced link. 4 tools: upload, file_info, list_uploads, delete_upload. Zero-config via `npx -y transfa-mcp`.
