# igorsaevets/page2ai-mcp

**Kind:** MCP Servers

**Description:** Convert any web page URL into clean Markdown for LLM context. Runs entirely on your machine with no external API calls and no API key. Preserves tables, code blocks and heading structure. Install via `npx -y @page2ai/mcp`.
