# korovin-aa97/talkthrough-mcp

**Kind:** MCP Servers

**Description:** Turn narrated screen recordings (or any local video/audio) into agent-ready data: local Whisper transcript, scene keyframes, OCR, full-text search, and wall-clock anchoring that maps spoken remarks to real timestamps for log correlation. No cloud, no LLM inside. `uvx talkthrough-mcp`.
