# alanpcf/brasil-data-mcp

**Kind:** MCP Servers

**Description:** Brazilian public data for AI agents — companies (CNPJ), addresses (CEP), banks (BACEN), national holidays — via [BrasilAPI](https://brasilapi.com.br). No auth, no API key. Install: `npx -y brasil-data-mcp`.
