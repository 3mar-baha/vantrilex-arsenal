# jaimenbell/discord-mcp

**Kind:** MCP Servers

**Description:** MCP server over the Discord REST API: read-only tools for listing channels, categories, roles, member roles and permission overwrites, plus write tools for channel, role, guild and message management that stay gated off by default. `pip install jaimenbell-discord-mcp`
