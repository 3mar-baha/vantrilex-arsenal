# dvdsosa/zotero-native-mcp

**Kind:** MCP Servers

**Description:** Read and write a local Zotero 10+ library through Zotero's own local API: collections, items, attachments from disk (linked or imported), indexed full text, BibTeX and CSL export, tags and saved searches. Deleting goes to Zotero's trash and is restorable. No Zotero plugin, no zotero.org API key and…
