# FileToPDF/filetopdf-mcp

**Kind:** MCP Servers

**Description:** Convert files (DOCX, XLSX, PPTX, images…), HTML, and Markdown to pixel-perfect PDFs via the FileToPDF API. Returns the PDF as an embedded resource or saves it to disk. Runs via `npx filetopdf-mcp` or a hosted Streamable HTTP endpoint; free API key in one click.
