# mlava/scholar-sidekick-mcp

**Kind:** MCP Servers

**Description:** Resolve any scholarly identifier (DOI, PMID, PMCID, ISBN, arXiv, ISSN, ADS bibcode, WHO IRIS URL) into structured CSL JSON, format in 10,000+ citation styles, or export to BibTeX/RIS/EndNote/Zotero RDF/CSV. Single or batch. Install: `npx -y scholar-sidekick-mcp`.
