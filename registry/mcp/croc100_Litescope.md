# croc100/Litescope

**Kind:** MCP Servers

**Description:** MCP-first operations toolchain for SQLite, Cloudflare D1, and Turso. Inspect, diff, migrate, monitor, back up, and repair databases over stdio. Read-only by default; writes are opt-in, dry-run first, and auto-snapshot before applying. `npx -y litescope mcp`
