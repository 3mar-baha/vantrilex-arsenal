# smeet666/mcp-animenewsnetwork

**Kind:** MCP Servers

**Description:** Search the Anime News Network encyclopedia for anime and manga, read cast, staff, episodes and studios, and follow the news wire. A name search upstream returns the full record of every match, 1.4 MB for a common query; this returns compact rows instead. No API key. `npx -y mcp-animenewsnetwork`
