# TrendTweekers/mintpdf

**Kind:** MCP Servers

**Description:** Converts HTML or Markdown into a styled PDF, or renders a public URL to PDF, and returns a download link. Markdown gets a default stylesheet so agent-written documents look right without design work. Free tier needs no signup. Install: `npx -y mintpdf-mcp`
