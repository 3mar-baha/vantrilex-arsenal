# jcooley8/pincushion-plugin

**Kind:** MCP Servers

**Description:** Visual feedback as agent work packets. Stakeholders drop pins on your live app; your AI coding agent reads each pin (selector, screenshot, DOM snippet, thread, acceptance criteria) via MCP and ships the fix, recording the commit/branch/PR on resolve. Install: `npx pincushion-mcp`.
