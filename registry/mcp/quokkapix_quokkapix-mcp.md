# quokkapix/quokkapix-mcp

**Kind:** MCP Servers

**Description:** Local MCP adapter/server for browser-only image workflows. Resize, compress, convert, remove backgrounds, strip metadata, watermark and export image packs through QuokkaPix without uploading source images to a processing server. `npx quokkapix-mcp`
