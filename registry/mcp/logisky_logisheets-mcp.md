# logisky/logisheets-mcp

**Kind:** MCP Servers

**Description:** A real Excel-compatible spreadsheet engine for agents, over [LogiSheets](https://github.com/logisky/LogiSheets) (Rust, via WASM). Deterministic formulas the model does not compute in its head, named blocks addressed by (block, key, field) instead of coordinates so references survive inserted rows, …
