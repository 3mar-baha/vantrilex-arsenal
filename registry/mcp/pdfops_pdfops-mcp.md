# pdfops/pdfops-mcp

**Kind:** MCP Servers

**Description:** Deterministic PDF tools for agents: inspect AcroForm fields, fill forms, merge PDFs, and generate invoice PDFs. Tools take file paths, so PDF bytes never transit model context; the same input produces byte-identical output. Keyless free tier. Install: `npx -y pdfops-mcp`.
