# VoxellInc/forge-mcp

**Kind:** MCP Servers

**Description:** Official MCP server for [Forge](https://voxell.ai), Voxell's hosted text-embedding API. Generate vector embeddings (turbo 1024d, pro 2560d, ultra 4096d; Matryoshka truncation) for semantic search and RAG. `npx -y @voxell/forge-mcp`
