# SynderAccounting/gl-importer-plugin

**Kind:** MCP Servers

**Description:** Import CSV/XLSX accounting data into QuickBooks Online or Xero via the [Synder Importer API](https://importer.synder.com). 19 tools covering imports, field mapping rules, post-import rules, and entity discovery. Install with `npx -y @cloudbusiness/gl-importer-mcp`.
