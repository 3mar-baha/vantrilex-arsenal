# TheWhiteWater/tube-bridge

**Kind:** MCP Servers

**Description:** Self-hosted YouTube research MCP with 17 tools for video and channel search, transcripts, comments, playlists, timestamped frames, and private local semantic corpora. Fourteen tools work without an API key. Install: `uvx tube-bridge`.
