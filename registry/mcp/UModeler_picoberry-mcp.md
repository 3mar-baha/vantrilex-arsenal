# UModeler/picoberry-mcp

**Kind:** MCP Servers

**Description:** Generate 3D models and images from a text prompt or reference images, then remesh, retexture, auto-rig, animate, and export GLB/FBX/OBJ through the PicoBerry API. Install: `npx -y @picoberry/mcp-server`.
