# marzukia/charted

**Kind:** MCP Servers

**Description:** Zero-dependency chart server that renders bar, line, pie, scatter, and more from JSON or CSV to SVG, HTML, PNG, or data URL. Built-in themes; PNG output renders inline in chat. Install via `uvx --from charted[mcp] charted-mcp`.

**Tags:** data-visualization, community
