# Vortx-AI/emem

**Kind:** MCP Servers

**Description:** Earth memory MCP server that gives AI agents signed geospatial facts and cite-able receipts for place-based questions. Covers elevation, land cover, surface water, vegetation, and built-up context. Public endpoint at `https://emem.dev/mcp`.
