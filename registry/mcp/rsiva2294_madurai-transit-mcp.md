# rsiva2294/madurai-transit-mcp

**Kind:** MCP Servers

**Description:** Model Context Protocol (MCP) server for Madurai CityBus public transit: direct and 1-transfer route planning across 966 bus routes and 3,000 stops, official TNSTC stage fare breakdowns, platform bay departures, and bilingual stop search. Install: `npx -y madurai-transit-mcp`.
