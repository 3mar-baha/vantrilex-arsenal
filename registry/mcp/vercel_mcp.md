# vercel-mcp

**Kind:** MCP Servers

**Description:** Official Vercel MCP server, remote-only at `https://mcp.vercel.com` with OAuth. There is no self-hostable package; add it to your agents with `npx -y add-mcp@2.4.1 https://mcp.vercel.com`.
