# esp4ce/infra-mcp

**Kind:** MCP Servers

**Description:** Read-only MCP server for on-prem Linux VMs and PostgreSQL over SSH. Check service health (systemd/journald), retrieve bounded logs, inspect DB state, and explore table schemas — without terminal access. Allowlist-gated, append-only audit log. `pip install infra-mcp`.
