# Kentucky-ai/opentakeoff

**Kind:** MCP Servers

**Description:** Construction plan takeoff on stdio — load a plan PDF, read the title block, adopt the drawing scale (never applied silently), one-click trace rooms, and export real-world quantities (square footage, linear feet, counts) with provenance receipts. Install via NPM: `npx -y opentakeoff-mcp`
