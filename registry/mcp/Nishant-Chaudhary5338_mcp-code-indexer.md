# Nishant-Chaudhary5338/mcp-code-indexer

**Kind:** MCP Servers

**Description:** Index any TypeScript/React repo (including monorepos) into a queryable code graph. Reverse queries (who-renders, who-calls, find-references), blast-radius analysis, dependency cycles, dead-code orphans, and symbol signatures — exposed over stdio. Install: `npx code-graph-indexer`.
