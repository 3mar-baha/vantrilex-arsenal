# ShieldZCash/shieldz-mcp

**Kind:** MCP Servers

**Description:** Keyless, non-custodial crypto payments. Create crypto payment links and tip jars with just a wallet address, no API key, no signup. Funds settle directly to the merchant’s wallet. Remote at https://shieldz.cash/mcp or `npx @shieldz/mcp`.
