# ayo-nci/bulkrender-mcp

**Kind:** MCP Servers

**Description:** Generate DOCX and PDF documents from reusable templates at scale. Upload a DOCX template once, call `generate_document` or `generate_batch` with JSON data, and receive a signed download link. Walk-in `acp_*` tools let agents pay per-session via Stripe with no account required. `npx bulkrender-mcp`
