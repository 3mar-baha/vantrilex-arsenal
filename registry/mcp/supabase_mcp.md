# supabase/mcp

**Kind:** MCP Servers

**Description:** Official Supabase MCP server. Connect via the hosted remote server at `https://mcp.supabase.com/mcp` (OAuth 2.1, no PAT) or install locally with `npx -y @supabase/mcp-server-supabase` and a personal access token to manage databases, auth, users, functions, storage, and more.
