# WenyuChiou/research-hub

**Kind:** MCP Servers

**Description:** Research workspace MCP integrating Zotero, Obsidian, and NotebookLM. Search papers (arXiv/Semantic Scholar/PubMed/CrossRef), ingest into Zotero, sync notes to Obsidian, verify NotebookLM briefs. All three external tools optional. `pip install research-hub-pipeline` then `research-hub serve`.
