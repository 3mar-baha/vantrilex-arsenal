# ni-c/osm-mcp

**Kind:** MCP Servers

**Description:** OpenStreetMap for travel planning: geocoding, walking/driving/cycling routes with correct FOSSGIS profiles, travel-time matrices, route optimization, isochrones and POI search. No API key required; client-side rate limiting keeps it inside the public services' usage policies. `npx -y osm-mcp`
