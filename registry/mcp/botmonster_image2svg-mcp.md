# botmonster/image2svg-mcp

**Kind:** MCP Servers

**Description:** Convert raster images (PNG/JPG/WEBP/TIFF) to SVG vector format. Single tool, accepts base64 or URL input; runs locally via `uvx image2svg-mcp` or as a Docker HTTP server.
