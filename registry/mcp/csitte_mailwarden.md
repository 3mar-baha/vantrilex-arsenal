# csitte/mailwarden

**Kind:** MCP Servers

**Description:** Native Gmail MCP server with full mailbox control — search, read, label, archive, trash, download attachments, and the feature no other Gmail server ships: snooze threads until a date. Every call hits the live Gmail API (no synced index that silently misses mail). Install with `npx -y mailwarden`.
