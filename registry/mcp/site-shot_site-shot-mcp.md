# site-shot/site-shot-mcp

**Kind:** MCP Servers

**Description:** Website screenshot API for AI agents. Real Chromium rendering, full-page capture up to 20,000px, country/geo proxies, and automatic ad & cookie-banner removal (cleaner images, fewer vision tokens). Two tools: `capture_screenshot`, `capture_full_page`. Install: `npx -y site-shot-mcp`.
