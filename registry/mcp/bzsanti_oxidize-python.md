# bzsanti/oxidize-python

**Kind:** MCP Servers

**Description:** Rust-powered PDF toolkit: create, read, and analyze PDFs; extract text and entities for RAG; convert to Markdown; split, merge, rotate, and reorder pages; add content, annotations, and form fields; and encrypt documents. Ships in the `oxidize-pdf` PyPI package — run locally with `uvx oxidize-mcp`.
