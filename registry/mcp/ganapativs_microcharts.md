# ganapativs/microcharts

**Kind:** MCP Servers

**Description:** Word-sized charts (sparklines, bars, bullets — 106 types) rendered to self-contained SVG with generated alt text. Three tools: find the right chart for a question, get its wiring, render it. Works in chat surfaces that can't run React. Install via `npx -y @microcharts/mcp`.

**Tags:** data-visualization, community
