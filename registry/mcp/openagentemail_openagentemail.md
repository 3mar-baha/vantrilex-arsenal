# openagentemail/openagentemail

**Kind:** MCP Servers

**Description:** Self-hosted email for AI agents: unlimited mailboxes on your own domain with a single `docker compose up`. OTP and verification-link extraction built in, long-poll `mail_wait_for`, read/unread state, plus a web dashboard for humans. Install with `npx -y @openagentemail/mcp`.
