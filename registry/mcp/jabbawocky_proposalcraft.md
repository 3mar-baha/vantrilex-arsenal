# jabbawocky/proposalcraft

**Kind:** MCP Servers

**Description:** MCP server that drafts client proposals in your own voice. Save 2-3 of your winning proposals, paste a new brief, and Claude generates a ready-to-send draft. No API key, no cloud — local storage only. `npx -y github:jabbawocky/proposalcraft`
