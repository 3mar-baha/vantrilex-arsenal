# slenderongithub/fix-protocol-mcp

**Kind:** MCP Servers

**Description:** Parse, validate, build, and explain FIX protocol trading messages (Logon, NewOrderSingle, ExecutionReport, and the rest of the session/order workflow). Fully offline — bundled FIX 4.4 field dictionary, no API keys or network calls. Install `pip install .`, run `fix-protocol-mcp`.
