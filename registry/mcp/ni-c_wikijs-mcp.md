# ni-c/wikijs-mcp

**Kind:** MCP Servers

**Description:** Search, read and edit a self-hosted [Wiki.js](https://js.wiki) 2.x, plus its assets, comments, users and groups (62 tools). Wiki.js' default search engine indexes only titles and descriptions, so `search_pages` names the active engine and `grep_pages` searches what is actually written in the pages.…
