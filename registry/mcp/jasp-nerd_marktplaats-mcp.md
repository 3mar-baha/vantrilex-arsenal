# jasp-nerd/marktplaats-mcp

**Kind:** MCP Servers

**Description:** Search Marktplaats.nl and 2dehands.be, the Dutch and Belgian second-hand marketplaces. Listings with price, condition and distance filters, full ad details, seller verification and reviews, categories, and new-listing monitoring. No account or API key needed. Install via `uvx marktplaats-mcp`.

**Tags:** e-commerce, community
