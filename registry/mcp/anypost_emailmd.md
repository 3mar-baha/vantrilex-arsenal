# anypost/emailmd

**Kind:** MCP Servers

**Description:** Write and preview emails from your assistant. Renders markdown into email-safe HTML that holds up in Outlook and Gmail, lints drafts for deliverability problems, and returns a live preview link. Hosted with no API key, or run it locally with `npx emailmd mcp`.
