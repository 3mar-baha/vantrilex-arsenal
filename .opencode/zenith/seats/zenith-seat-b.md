seat carries its model plus its variables into the session; a name
displayed and dropped at runtime is not a selection.

- Model: muse-spark-1.3-contributor via opencode-go, free tier, seat default and owner-overridable at pick time
- Variables:
  - depth: 2
  - lane-scope: scout plus plan
  - anchor-cadence: every session anchor
  - refresh-scope: directives plus load plus failure log
  - arbitration: read-only observation, no rulings
  - tool-surface: read plus gate set, no mutating tools

Scope note: recon-heavy sessions where the register needs directives, load,
and failure memory refreshed, while arbitration stays observed and unruled.
