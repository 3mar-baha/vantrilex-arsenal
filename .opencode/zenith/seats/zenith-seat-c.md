# Zenith Seat C — Secretariat

Pre-made variable seat, selectable from the side picker. Selecting this
seat carries its model plus its variables into the session; a name
displayed and dropped at runtime is not a selection.

- Model: muse-spark-1.3-contributor via opencode-go, free tier, seat default and owner-overridable at pick time
- Variables:
  - depth: 1
  - lane-scope: records only
  - anchor-cadence: every session anchor
  - refresh-scope: log append only
  - arbitration: none, secretariat never rules
  - tool-surface: read plus log append, no work orders

Scope note: record-keeping posture. Keeps the register, the refresh log,
and the ledger current, issues no work orders, rules on nothing.
