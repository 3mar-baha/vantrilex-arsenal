## 3. Discipline rules (normative core of this spec)

- D1 propose-against-baseline: every proposal names its defined check and its observed behavioral difference, and is evaluated against the shipped baseline, never against a modified copy. An unmeasured proposal — no defined check, no baseline comparison — is REFUSED, never accumulated.
- D2 gate-survivor-only accumulation: only distilled lessons and changes that survived the standing gates accumulate. No change without evidence accumulates, under any reading of improvement. Gate verdicts belong to the standing gates; this discipline records, never overrules.
- D3 governed check budget: check spend is capped and ordered. Priority order C1, then C2, then C3 (section 4). A task outside the named classes gets no check by default; spending a check there requires a recorded reason at design time, never silence.
- D4 no check for every task by default: the default is no check. The budget holder proves the class earns the check; the task never assumes it.
- D5 frame-reservation hold: frame re-evaluation is RESERVED for this slot's design time, when a measured record exists. The reservation is recorded here and never adopted here. Any adoption attempt on this seat returns HELD — explicit owner decision required at design time. Auto-adoption is refused by name.

## 4. Check-budget classes (named, governed)

- C1 harvest-cycle review: recurring review of the weekly harvest record. Highest recurrence, highest value: it is the record every later judgment measures against.
- C2 overlay-application review: recurring review of self-repair overlay applications. Second priority: overlays change behavior, so each application earns its check.
- C3 check-mechanism calibration: recurring calibration of the check mechanism itself. Third priority: the ruler is measured so the measurements stay honest.
- Order: C1 first, then C2, then C3. A shrinking budget cuts from C3 upward; C1 is cut last. Classes outside C1-C3 get no check by default per D4.
- The measure of a class's value (what earns budget before others) is OPEN per section 6; the order above is the initial governed order, re-measurable at design time, never a final ranking.
