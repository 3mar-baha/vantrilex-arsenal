## Scope

## Procedure

1. Name the trigger: the exact case or failure that taught the lesson.
2. Quote the evidence: commands, exits, and file and line references behind the claim.
3. State the limit: where the learning stops applying and what would change the verdict.
4. Keep counts honest: counted things say how they were counted; uncounted things say so.
5. Never upgrade a suggestion into a failure and never soften a hard rule in the retelling.
6. Date every note; never bump a date without re-running the procedure behind it.
