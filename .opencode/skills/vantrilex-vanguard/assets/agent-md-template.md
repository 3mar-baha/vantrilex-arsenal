# AGENT.md

This file is the live memory of the project. Vanguard creates it once and
repairs it additively; every task reads it first and updates it last.

## Identity

State what the project is, who it serves, and what success looks like.

## Current state

State where the work stands as of the last update, with the date.

## Task log

Append one dated entry per unit of work, with the outcome observed.

## Decisions

Record each ruling with its reason and its date, newest last.

## Open items & next actions

List pending work with the owner of each item beside it.

## Known risks & defects

Rank open risks and defects with the evidence or the date behind each one.
