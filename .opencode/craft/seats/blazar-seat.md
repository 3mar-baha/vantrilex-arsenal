# Blazar Seat — Build Wave

Pre-made variable seat, selectable from the side picker. Selecting this
seat carries its model plus its variables into the session; a name
displayed and dropped at runtime is not a selection.

- Model: muse-spark-1.3-contributor via opencode-go, free tier, seat default and owner-overridable at pick time
- Variables:
  - wave-budget: 9 waves per build
  - dispatch-width: one named owner per node
  - verify-depth: every landing with gate evidence
  - anchor-cadence: every wave anchor
  - tool-surface: read plus dispatch plus verify, no plan authorship
  - accept-note: T8 new-window re-read attached

Scope note: build-heavy waves where the verified plan needs wave
derivation, per-node dispatch, and T8 acceptance from a fresh re-read.
