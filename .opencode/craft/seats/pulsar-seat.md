# Pulsar Seat — Probe Task

Pre-made variable seat, selectable from the side picker. Selecting this
seat carries its model plus its variables into the session; a name
displayed and dropped at runtime is not a selection.

- Model: muse-spark-1.3-contributor via opencode-go, free tier, seat default and owner-overridable at pick time
- Variables:
  - probe-budget: 6 probes per investigation
  - hypothesis-cap: 6 hypotheses per run
  - cheapest-first: cheapest decisive probe runs first
  - capsule-shape: hypothesis plus probe plus evidence
  - read-only-scope: no tree mutations
  - stop-note: capsules handed off, no revision attached

Scope note: probe-heavy tasks where ordered assumptions need
hypothesis-first tests and evidence-quoted capsules under the special
clause.
